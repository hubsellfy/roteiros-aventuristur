# Fontes da marca Aventuristur

Estes arquivos são cópias dos logos institucionais existentes no repositório
`hubsellfy/aventuristur`. Os originais do site não foram modificados.

| Arquivo no fork | Origem no site | SHA-256 |
| --- | --- | --- |
| `mark.png` | `site/public/images/shared/logo-aventuristur.png` | `26c3038fa7f74d38e3a59bd6a92d598dd0a70cd33114419e89a6df95b27b75ab` |
| `mark-transparent.png` | `site/public/images/shared/logo-aventuristur-sem-fundo.png` | `d97fb6b52bcf765370178c85649d12d9d45ce697d9278040ec9a7de9ee932a84` |

O script `../rebrand/apply.mjs` gera os SVGs de interface a partir dessas
fontes. O pré-build do cliente gera os PNGs do iPhone, Android e da PWA.
O ícone usa o azul `#0a6fc2` do site; a versão maskable mantém o desenho
dentro da área segura para recorte. O dono precisa aprovar o resultado visual
antes do merge da etapa 2.
